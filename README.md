## 三分钟怎么玩

页面顶部四个入口：**帮我选 ｜ 跟我换 ｜ 选品攻略 ｜ 我的**

1. **发起一个投票**
   进「帮我选」→「发起投票」。可以填标题、加候选（2—8 个）、写价格、设参数，
   也可以在最上面输入一句话（例：`1500 左右的降噪耳机，通勤用`）点「起草候选」，
   会按品类和预算生成三个候选骨架，一键填进表单。

2. **投一票**
   打开任意投票，登录后点候选即可。想要账号的话，登录框里手机号填
   `13800138823`、验证码填 `123456` 就是演示账号。任意 11 位手机号 + 任意 6 位验证码都能注册新账号。

3. **把结论存成攻略**
   投票结束后在结果区点「存成攻略」，会生成"预算档位 / 关键参数 / 适用人群 / 避坑点"四区块。
   攻略进「选品攻略」，也进「知识库」（`#/kb`，攻略页顶部有切换）。

4. **看看技能怎么串起来**
   页脚有「链路演示」（`#/flow`）：起草候选 → 发起投票 → 计票 → 沉淀攻略 → 交换匹配，
   五步一条链路跑完，每一步的输入输出 JSON 都能展开看。

## 关于数据

投票与票存在云端（Supabase 托管数据库），**分享出去的链接在别人的设备上能打开、也能投**。
页面本身仍然是一份静态文件，离线时会退回本机数据继续用，只是别人看不到这一场。

「我的」页可以导出 / 导入全部数据（JSON）。想清空重来也在那里。

首次打开会自动生成演示种子数据（若干投票、攻略、交换单），方便直接看效果。

## 和 DeepWorks 的关系

判断逻辑由四个 DeepWorks 技能承担，每一个都是**纯函数、JSON 进 JSON 出**：

| 技能 | 做什么 | 自检 |
| --- | --- | --- |
| `poll-result` | 计票、平票建议、信用门槛、到期判定 | 47 项 |
| `poll-designer` | 一句话解析品类与预算，起草候选骨架 | 29 项 |
| `guide-writer` | 投票结论 → 四区块攻略 | 19 项 |
| `swap-matcher` | 交换单按品类 / 价值 / 成色 / 新鲜度打分排序 | 23 项 |

四个技能是本项目的 DeepWorks 技能，开发与演示时由 DeepWorks 加载执行。
`#/flow` 页是它们在浏览器里的串联演示；网页本身是展示与表单层，
打开页面时跑的是与技能同口径的浏览器镜像，两者靠同一组用例锁住结果一致。

**把技能装回 DeepWorks**（可选，不装也能正常浏览网页）：

1. 新建一个工作区，在它下面建 `.opencode/skills/` 目录
2. 把 `source/skills/` 里的四个目录整体复制进去
3. 重新打开该工作区，四个技能会出现在可用技能列表里
4. 验证：`python source/skills/poll-result/scripts/selftest.py`，应输出 47 项全过

四个技能都是纯 Python，不依赖第三方库，只需要 Python 3.8 及以上。

## 已知限制（写在明处）

- 云端表目前是「匿名可读写」（演示期权限），没有防刷与防篡改；正式使用需切到按账号隔离的策略。
- 截止时间、轮次、信用分仍在浏览器里判定，改系统时间可以绕过——判定逻辑留在技能里，是刻意为之。
- 私密投票的"仅链接可见"靠的是链接不可猜，没有权限校验。
- 站内消息只在本机投递（跨设备不同步）。
- 判定（计票 / 起草 / 攻略 / 匹配）全部由四个技能的浏览器镜像完成，数据库里没有任何计算逻辑。
- 交换只做撮合，不涉及支付与担保。
